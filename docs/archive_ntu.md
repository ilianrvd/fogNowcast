# Архив на НТУ: `archive-YYYY-MM`

> Чернова (етап 1). Нормализиран архив на пътните метеостанции, получен от отворените данни на Национално тол управление.

## Лиценз и посочване на източника

Данните на НТУ са под **CC BY 4.0**. Всеки файл тук носи полето `source` и бележка за автора: „Данни: Национално тол управление (bgtoll.bg), CC BY 4.0. Обработка: fogNowcast." При използване на архива НТУ се посочва.

## Къде се намира

Клонове `archive-YYYY-MM` в repo-то (по един на месец, без обща история с `main`). Всеки съдържа:

| Файл | Съдържание |
|---|---|
| `ntu_YYYY-MM.csv.gz` | нормализираните записи за месеца |
| `ntu_stations.json` | обобщение по станции за целия архив (общо за всички месеци) |
| `ntu_import_meta.json` | как е направен импортът: броячи, правила, лоши файлове |
| `README.md` | посочване на източника |

Импортът се пуска ръчно: workflow `import-ntu-archive` (`publish=true` публикува клоновете).

## `ntu_YYYY-MM.csv.gz`

UTF-8, запетая като разделител, първи ред е заглавие. Редовете са подредени по `time`, после по `id`. Празно поле = няма стойност.

| Колона | Единица | Описание |
|---|---|---|
| `time` | ISO 8601, UTC | Времето на измерването от полето `time` на записа. **Никога от името на файла.** |
| `id` | | `NTU:<station_id>` |
| `t` | °C | `air` |
| `rh` | % | `humidity`; 0 в източника е липсваща стойност; над 100 се реже до 100 |
| `td` | °C | от `t` и `rh` по Magnus (коефициенти на Alduchov–Eskridge, 17,625 и 243,04) |
| `t_surface` | °C | `surface` (настилка); 0 в източника е липсваща стойност |
| `pressure_hpa` | hPa | `pressure`, налягане на станцията, не е редуцирано до морското равнище; 0 е липсваща стойност |
| `wind_kt` | kt | `wind` в източника е km/h, делено на 1,852 |
| `wind_dir` | ° | `wind_dir`, откъдето духа; празно при `wind_zero_both` |
| `flags` | | флагове, разделени с `|` |

### Флагове по запис

| Флаг | Условие |
|---|---|
| `t_missing` | няма `air` |
| `surface_missing` | `surface` = 0 |
| `surface_suspect` | `surface` под −40 или над 80 °C, или по-далеч от `air` с над 30 °C |
| `rh_missing` | `humidity` = 0 |
| `rh_over_100` | `humidity` над 100 (записва се 100) |
| `pressure_missing` | `pressure` = 0 |
| `wind_missing` | няма `wind` |
| `wind_zero_both` | и `wind`, и `wind_dir` са 0: тишина или липса, не може да се различи. `wind_kt` е 0, посоката е празна. |

## Какво се пропуска при импорта

Записите, които не влизат в таблицата, се броят в `ntu_import_meta.json` (`counts`):

| Причина | Правило |
|---|---|
| `dropped_stale` | записът е по-стар от снимката с над 20 мин. Така отпадат „призрачните" станции с една замръзнала стойност (напр. от 2023) и повтарящите се стари записи. |
| `dropped_future` | записът е по-нов от снимката с над 20 мин |
| `dropped_duplicate` | вече има запис със същото (`station_id`, `time`) |
| `dropped_invalid` | липсва `station_id` или `time` не се разчита |

Снимки, които не се четат (счупен JSON), са в `bad_files`. Името на файла е в местно време (Europe/Sofia); за повтарящия се час при смяната на часа се пробват и двете тълкувания и се взема това, което дава свеж запис.

## `ntu_stations.json`

```json
{
  "generated_at": "...", "source": "...",
  "stations": {
    "NTU:1": {
      "name": "Мотел Ихтиман", "name_en": "Motel Ihtiman", "lat": 42.426981, "lon": 23.854053, "elev_m": null,
      "first": "2026-01-27T08:00:00Z", "last": "2026-11-24T21:45:00Z", "rows": 26204,
      "active": true, "t_surface_usable": true, "rh_usable": true,
      "missing_share": {"surface_missing": 0.0, "rh_missing": 0.0, "pressure_missing": 0.0},
      "repeat_share": 0.01, "frozen_suspect": false, "rh_saturated_share": 0.036, "dropped_stale": 5
    }
  }
}
```

| Поле | Правило |
|---|---|
| `active` | последният запис е в рамките на 3 дни от края на архива |
| `t_surface_usable` | `surface_missing` под 50 % от редовете |
| `rh_usable` | `rh_missing` под 10 % от редовете |
| `repeat_share` | дял редове, чиито стойности са същите като на предишния ред на станцията |
| `frozen_suspect` | `repeat_share` над 10 % (замръзнал предавател или датчик) |
| `rh_saturated_share` | дял редове с `rh` ≥ 99,5 %. Информативно: може да е мъгла, а може да е залепнал датчик. |
| `elev_m` | `null`, в източника няма. Идва от DEM в отделна стъпка. |

Праговете са първоначални и се уточняват с верификацията.
