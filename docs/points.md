# Общ списък на точките: `static/points.json`

Единният списък на летищата, станциите и участъците. Всички проекти ползват едни и същи идентификатори.

> Собственик: **nowcasting-public** (решение от 2026-11-25). Файлът тук в fogNowcast (`static/points.json`) е проектът на съдържанието, подготвен за предаване. Координатите и височините на летищата са от AIP. Докато nowcasting-public не го публикува, fogNowcast ползва това копие.

## Идентификатори

| Тип | Формат | Пример |
|---|---|---|
| Летище | ICAO код | `LBSF` |
| Станция на НТУ | `NTU:<station_id>` | `NTU:57` |
| SYNOP станция | `SYNOP:<WMO индекс>` | `SYNOP:15614` |
| Участък от път | `SEG:<ref>-<номер>` | `SEG:A1-012` |

Веднъж даден, идентификаторът не се сменя. Ако една точка отпадне, тя остава в списъка с `"active": false`.

## Структура

```json
{
  "generated_at": "2026-11-25T00:00:00Z",
  "source": "fogNowcast static/points.json",
  "version": 1,
  "points": [
    {"id": "LBSF", "type": "airport", "name": "София", "name_en": "Sofia",
     "lat": 42.696667, "lon": 23.411389, "elev_m": 531}
  ]
}
```

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Идентификатор (виж таблицата по-горе). |
| `type` | string | `airport`, `ntu`, `synop`, `segment` |
| `name`, `name_en` | string | Име на български и на английски. |
| `lat`, `lon` | number | WGS84. За участък: средата му. |
| `elev_m` | number или null | Надморска височина. При НТУ няма такова поле в източника, затова височината идва от DEM (етап 1). |
| `active` | bool | По подразбиране `true`. |

`version` се увеличава при всяка промяна в списъка.

## Състояние

В етап 0 списъкът съдържа само петте летища (координатите и височините са от AIP, сверени на 2026-11-25). Станциите на НТУ и SYNOP се добавят с вноса си (етап 1), а участъците в етап 3.
